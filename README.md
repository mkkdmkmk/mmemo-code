# Memo Code — AI Coding Workspace

An AI-powered coding workspace designed to help developers build, understand, modify, and debug software through natural language.

## Overview

Memo Code explores a modern AI-native development experience inspired by tools such as AI coding agents and intelligent developer workspaces.

Instead of treating AI as a simple chatbot, the product integrates AI directly into the coding workflow.

The core interaction is:

**Describe → Analyze → Generate → Review → Iterate**

## UX Challenge

AI coding tools can become complex very quickly.

The challenge was to create an interface that allows developers to work with AI while keeping the relationship between:

**AI → Code → Files → Changes → Developer**

clear and understandable.

The experience is designed to keep developers in control while making AI actions transparent and easy to review.
